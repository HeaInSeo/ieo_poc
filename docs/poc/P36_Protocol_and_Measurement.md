# P36 · 표준 형식의 작성과 결정 지원

v1.3.3 · 작업 04-16. 현재 미실행. 평가자: 사용자 본인 1명(2026-11-12 리뷰). 04-09 이후, 07-01/P26 이전, S0 선행 아님.
가설: 표준 양식과 보고가 자유 서술보다 작성/결정을 빠르고 정확하게 돕는다.
이 문서는 시험 절차이며 사용자에게 실제 평가 시나리오·정답을 미리 보여 주지 않는다.

## 실행 전 동결 · 01-03

[개정 v1.3.3-A1](Amendment_v1.3.3-A1.md): 01-03은 단계별 동결이다. 아래 항목은 04-16 첫 실행 전에 동결 증거가 있어야 하며(동결 대장 L05, 07-04 재측정은 L06), 없으면 시작하지 않는다. 사용자 결정 D9로 수치는 초기 탐색 기준이 채택됐다(표준 일치 ≥ 5/6, 결정 시간 중앙값 표준 ≤ 자유×1.2·건당 ≤ 300초, 추가 질문 표준 ≤ 자유, 비열등 일치 수 표준 ≥ 자유−1, 치명적 오해 0, 재시험 1회). 정답은 독립 출제·채점 담당만 접근하며, 동일 UID의 0700 디렉터리만으로 봉인 완료를 주장하지 않는다.

치명적 오해 0건은 고정 필수다. 나머지 기준이 공란이면 시험을 시작하지 않는다. 결과를 본 뒤 수치를 정하지 않는다.
독립 담당은 개발 작성 맥락을 받지 않고 원본 요구/증거로 정답을 작성한다. 개발자가 시나리오와 정답 모두를 만들지 않는다.
봉인 파일은 사용자·작성자에게 공개되는 이 ZIP/이미지/현황에 넣지 않는다. 별도 승인된 비공개 평가 저장 위치에 원본·digest를 남긴다.
시험 전 공개 기록에는 봉인 digest·담당·개수·기준 revision·고정 시각만 적는다. 사용자는 평가 전 정답과 실제 시나리오 목록을 보지 않는다.

## (a) 작성

같은 요구의 자유 서술 원문을 먼저 보존하고 사용자가 사람이 쓰는 양식으로 실제 스프린트 3건을 작성한다.
자유 서술→명세 변환은 별도 새 세션에서 같은 원 요구만 받아 수행한다. 구조화 변환 결과를 대조 세션에 주지 않는다.
작성 시간(초), 등록 거부 횟수/필드별 사유, 거부 응답만 읽고 해결한 횟수/전체 거부 수, 에이전트 재질문 수를 기록한다.
거부가 0건이면 자가 교정 비율은 N/A(분모 0)다. 자유 서술 대조는 변환 중 재질문 횟수를 비교한다.
동일 요구를 먼저 접한 순서·학습 편향을 기록하고 이를 독립 집단의 시간 절감 효과로 일반화하지 않는다.
검토된 양식 3건은 원문/변환/거부/보정/승인 버전을 함께 07-01의 입력으로 재사용한다. 중복 작업/신규 산출로 이중 집계하지 않는다.
P36에서는 백로그의 실제 개발을 배정하지 않고 작성·등록 검토만 수행한다. 07-01에서 현재 코드·권한·범위를 재확인한다.

## (b) 결정

유형은 결정 불필요 상태 변경, 범위, 일정, Guardrail 반려 수용, 한도 대기, 외부 결과 미확인, 지연 위험, 개발 claim과 verified 불일치를 포함한다.
각 시나리오의 사실·근거·선택지·영향·시한은 두 표현에서 같게 한다. 자유 서술에서 사실을 빼거나 길이를 부당하게 늘리지 않는다.
독립 담당이 12건 이상을 난도 유사 두 묶음(최소 각 6건)으로 배정하고 각 시나리오는 사용자에게 한 형식만 제시한다.
제시 순서·묶음 배정·표준/자유 서술 균형은 실행 전에 고정한다. 같은 사실/정답을 바꿔 이름만 다른 시나리오로 두 번 제시하지 않는다.
결정 완료 시간은 보고 공개부터 최종 선택까지의 경과다. 중단 시간 처리·시각 수집/정답 채점은 01-03에서 고정한다.
각 건에 결정 시간, 정답 일치, 원본 증거 재열람 횟수, 추가 질문 횟수, 결정 불필요→필요/필요→불필요 오인, 자유 불편을 기록한다.
결정 불필요의 정답은 “결정 없음”도 명시적 답이다. 안전상 필요한 대기는 실패한 사용자 결정과 혼동하지 않는다.

## (c) 채택·재시험

표준 형식이 치명적 오해 0건이고 사전 동결한 일치율/시간/질문 수 기준과 자유 서술 대비 비열등 조건을 모두 충족해야 채택한다.
모든 개별 원 측정값·분모·두 묶음의 난도 차이·정답 채점·오인 두 방향을 공개 결과에 남긴다. 평균만으로 치명적 오해를 감추지 않는다.
미충족이면 형식을 새 버전으로 고치고 기존 평가에 노출되지 않은 새 시나리오에서 사전 한도 내 재시험한다. 원 실패는 보존한다.
PASS 전에는 필수 사람 검증을 완료로 집계하지 않는다. FAIL/INCONCLUSIVE·예산 종료 시 영향·대안/재개 조건을 보고한다.
