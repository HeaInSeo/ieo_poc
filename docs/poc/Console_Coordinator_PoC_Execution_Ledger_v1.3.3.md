## 2. 우선 실행 순서와 상태 규칙

**v1.3.3-A1 읽기 규칙**([개정](Amendment_v1.3.3-A1.md)): 이 장부에서 01-03에서 동결/고정한다고 쓴 수치·표본·예산·기대값은 해당 첫 실행 전 동결로 읽는다. 담당·시점·차단 조건은 [동결 대장](reports/tasks/01-03/staged-freeze-20261112/freeze_register.json)의 later 항목이며, 동결 증거가 없으면 그 실행을 시작하지 않는다. 작업 수는 그대로다.

v1.3.3 변경 기록: 원 72작업/30실험 → 73작업/31실험. 이유: 2026-11-12 리뷰의 P36 추가. 기존 ID와 후속 12/5는 유지하며 04-16은 04-09 이후, 07-01 전에만 추가한다. S0 경로에는 넣지 않는다.

1. 01의 명세·보고·런타임·환경을 고정하고 02의 최소 후보를 만든다. 첫 부트스트랩은 고정된 외부 절차가 담당한다.
2. **02 직후 EARLY-01 관통 조사**를 수행한다. POC-01~05의 실제 에이전트/API/PostgreSQL 흐름에 PR·독립 검토·시험 보고를 연결한다. 조사 1건의 범위와 임시 예산(28,800초·검토 4회·토큰 3,000,000)은 01-03에서 채택했고, 계측·독립 기대값의 동결 증거는 첫 실행 전에 요구한다(동결 대장 L02). 이 조사는 73개 분모/실험 PASS에 가산하지 않는다.
3. 공통 카탈로그 전체보다 **04-03 첫 실제 PR → 05-05 최소 S0 → 06-01 자기 repo 변경**을 우선한다. 선행이 준비된 개별 작업을 실행하며 앞 스프린트 전체의 종료를 숨은 조건으로 요구하지 않는다.
4. 07의 기존 승인 제품 환경 경로와 03/06의 공통 카탈로그·신규 셋업 경로를 독립 진행한다. P20/P24는 해당 카탈로그의 P25/P22/P23 증거가 필요하다.
5. 08 확장과 09 종합을 연결한다. 07/P26 실제 기록 이후에만 후속 연구를 시작한다. 연구의 성공을 주계획의 선행으로 추가하지 않는다.

작업 상태는 **미착수·준비됨·진행·검수 중·검수 완료·조건 대기·종료 미충족** 중 하나다. 합계는 현재 분모와 같아야 한다. 재시험·회차·S0~S3는 작업 수에 가산하지 않는다. 검증 PASS는 원본 증거·독립 판정 연결로 충분하고, 평가 작업 및 FAIL/INCONCLUSIVE에는 공통 처분·재개/종료 한도를 남긴다. 보고 v0의 작업 중/작업 보유 대기/사람 결정 대기/일 없음은 운영 상태 축이며 이 검수 상태와 구분한다.

**선행의 의미:** 기본은 선행 작업의 해당 버전 검수 완료다. 종합 09-03의 선행은 결과 기록 확보(`result_recorded`)이며 FAIL/INCONCLUSIVE/미실행 사유를 숨기지 않는 보고를 만들 수 있다. 그 기록 확보를 기능 PASS나 원 작업의 검수 완료로 바꾸지 않는다. 실제 전환은 P27-L의 별도 승인 창과 정상 권한 경로를 따른다.

## 4. 명세 v0로 표현한 작업 목록

대상 논리 repo는 `console-coordinator`이며 실제 저장소 URL·런타임·승인 출처·한도는 01에서 바인딩한다. PoC 구현/시험 자산의 소유 repo와 P26 표본 대상 repo를 구분한다. NodeKit/Sori 실행은 repo별 표본 명세를 따로 등록한다. 현재 JSON은 `draft`라서 실행 가능 등록의 통과를 주장하지 않는다. 일정은 각 스프린트의 착수 조건/미확정 이유와 함께 JSON에 있으며, 실제 산출·검토 속도를 얻은 뒤 근거와 범위를 붙여 산정한다.

## 6. 기준선 변경과 현재 검산

v1.2의 76개에서 연구 10개를 후속으로 옮기고, 명세/보고 표준 2개·지속성/자식 검증 2개·최소 이미지 검증 1개·실제 quota 분리 1개를 추가해 이전 기준선 **72개**였다. v1.3.3은 P36(04-16) 한 작업을 추가해 **73개**다. T09 구현과 P33 합성 검증 2개는 종합으로 이동했으며 수량을 늘리지 않았다. 기존 11 스프린트의 연구 09/10을 분리하고 종합 11을 현재 09로 재번호화했다. 반드시 계획 버전과 ID를 함께 인용한다.
