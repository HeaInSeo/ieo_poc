관측 불가 quota는 P05-Q의 INCONCLUSIVE/조건 대기로 남기며 최소 S0를 막지 않는다. 실제 자동 복구·전체 필수 기능의 충족으로 보고하지 않는다. 일 없음은 역할별 배정·착수 가능 작업·미확정 효과/활성 자식/저장 상태를 대조해 판정한다. 역할별 상시 유지/idle 정지는 결정 필요이며 P34의 복원 시간·자원을 먼저 측정한다. 조용한 프로세스만으로 정지하지 않는다. U3에서는 같은 호스트 단계 컨테이너 둘, S3는 두 Pod 모두 PSA Restricted 및 역할별 NetworkPolicy의 실제 효과를 확인한다.

01-04 착수 시 표 순서와 무관하게 **동시 세션 수→자격 분리/공급자 한도 분리**부터 확인한다. 어느 하나 불가 또는 관측 불가이면 다음 작업으로 넘어가지 않고 영향·대안·재개 조건을 보고한다. 역할별 로컬 예산 분리를 공급자 quota 분리 성공으로 쓰지 않는다. 두 probe 원본은 명령·버전·기동/종료 시각·로그·자격의 비밀 없는 식별·quota group/확실성을 남긴다.
