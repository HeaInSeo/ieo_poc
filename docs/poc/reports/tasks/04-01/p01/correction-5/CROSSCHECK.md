# F03 사전 대조

| 요구 | 실행 절차와 관측 |
| --- | --- |
| REQ-11 | 모든 출처 접근을 강제 경계로 통과시킨다. 초기화한 정상 회차마다 허용 1건과 나머지 0건을 전체 trace로 확인한다. 별도 음성 대조는 예고되지 않은 ID의 실제 경계 호출을 주입하고, 거부 이벤트와 미전송을 관측하며 같은 검사기가 해당 trace를 실패시키는지 확인한다. |
| REQ-12 | 발행자 검증본의 201·영속 레코드와 미검증본의 422·불변·읽기 0건을 확인한다. |
| REQ-13 | 발행자 정상 대조와 reader·역할 없는 주체 각각의 403을 확인한다. 역할 없는 자격은 인증 성공과 빈 역할 집합을 별도 증거로 확인한다. 두 거부 모두 저장소 불변과 읽기 시도 0건을 확인한다. |
| 기존 AC-14 | 두 회차를 독립 초기화한다. 201 직후 전체 저장소에서 원본 ID와 모든 필드를 고정한다. 422, reader 403, 역할 없는 주체 403 각각 직후 전체 저장소에서 원본 한 건의 동일성을 확인한다. |

이 대조는 설계의 시험 절차를 평가한다. 격리 코디네이터 재현은 해당 설계에 대한 독립 판정과 구현 배정만 실행한다.
