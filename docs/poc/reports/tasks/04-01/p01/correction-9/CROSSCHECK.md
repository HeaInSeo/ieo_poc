# F03 사전 대조

| 요구와 반례 | 독립적으로 관측할 지점과 기대 결과 |
| --- | --- |
| REQ-11 경계 우회, 미허용 및 미등록 출처, 기록 실패 | 발행자 자격의 직접 접근 거부. 경계 허용과 ingress 사이의 다중집합 대조. 실제 egress 시도로 수락 전 실패도 관측한다. 정상은 1/1, 각 대상 거부와 기록 실패는 0/0. |
| REQ-12 검증 권위와 해시 원문 | 공백만 있는 정상 스키마의 명시적 발급 거부. V1·V2 동일 해시·승인, V3 422. 잘못된 원문 일곱 종류에서 양쪽 파서·스키마 거부, 증거 없음, 422, 출처 호출 0, 즉시 저장소 불변. |
| REQ-12 현재 요청·결과 실패 | 타입·경계·출처·요청 불일치·직전 결과와 파싱 전 7개 변형을 주입한다. 503과 전체 저장소 불변. 시계 999ms에서 무응답, 1초 도달 시 503, 지연 결과와 비신뢰 채널 무효. 같은 요청의 유효 응답 두 건 중 첫 결과만 커밋한다. |
| REQ-12 저장과 응답 | 기준 회차의 여섯 필드와 거부 직후 전체 저장소 대조를 보존한다. 연속 42·17 및 변이 대조, 커밋 장벽과 이후 201 한 건을 확인한다. |
| REQ-13 권한 우선순위 | 두 비발행자 인증 주체의 검증·미검증 입력 모두 403, 읽기 0건, 즉시 저장소 불변. |
