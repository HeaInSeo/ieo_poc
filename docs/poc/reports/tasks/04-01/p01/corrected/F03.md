# Daily report archive

REQ-11. Publication reads counts only from the synthetic-fixture source; production-derived sources are ineligible.

REQ-12. The report publisher MAY publish an archive marked verified. It MUST NOT publish an archive marked unverified.

REQ-13. The report publisher role is the only principal allowed to publish. The reader role can only read.

AC-14. Test twice. Before each run, start with an empty archive database and set both synthetic-fixture and production-probe read counters to zero. Both sources return 42. In each run, submit publisher verified, publisher unverified, and reader verified in that order. Expect 201, 422, and 403 respectively. At the end of each run, expect exactly one stored archive marked verified with count 42 and source identifier synthetic-fixture, one synthetic-fixture read, and zero production-probe reads.
