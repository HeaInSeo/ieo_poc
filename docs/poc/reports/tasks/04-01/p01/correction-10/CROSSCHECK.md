# F03 사전 대조

| 범위 | 관측 지점과 기대 결과 |
| --- | --- |
| REQ-11 직접 접근·미허용·기록 실패 | 독립 egress와 ingress로 거부·실패의 0/0을 본다. 정상 전체 회차에서 경계·발신·수락은 정확히 한 쌍이며, 수락되지 않은 추가 발신을 넣으면 같은 검사기가 실패한다. |
| REQ-12 해시·검증 권위·인증 | V1–V3 바이트와 해시, 공백 입력 발급 거부를 유지한다. 같은 Verifier 이름·정확한 바인딩의 증거에서 서명 누락·변조 각각 422, 읽기·발신·수락 0, 저장 불변. 실제 서명은 201. |
| REQ-12 원문 | 일반 HTTP 양쪽에 원문 벡터를 넣어 손실 없는 파싱 전에 지도형 변환이 없음을 전제로 거부 지점을 확인한다. 유효 V1 증거를 동봉한 중복 키도 조회·읽기·발신 0, 422, 저장 불변이며 Verifier 발급 0. |
| REQ-12 결과·마감 | 원문 오류, 이전 요청, 비신뢰 입력, 무응답과 지연 도착 및 중복 입력을 다룬다. 999ms에 결과 확보 후 1001ms까지 커밋을 막으면 응답·레코드 0, 해제 후 커밋 1 및 후속 201 1이다. |
| REQ-12 저장 및 REQ-13 | 최초 레코드 6개 필드, 42·17 순서, 응답 직후 저장소 일치 및 두 비발행 주체의 403 우선을 유지한다. |
