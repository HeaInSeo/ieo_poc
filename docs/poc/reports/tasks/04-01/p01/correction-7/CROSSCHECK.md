# F03 사전 대조

| 반례 | 검출 기준 |
| --- | --- |
| Verifier와 발행기가 다른 바이트를 해시 | 두 서비스에서 V1·V2의 공통 바이트와 SHA-256 일치. V3는 내용만 바뀌며 기존 증거로 422·출처 읽기 0·즉시 저장소 동일. |
| 게이트웨이 장애에도 201 또는 쓰기 | 유효 증거로 기록 실패·카운트 누락을 각각 주입한다. 두 응답 모두 503·즉시 저장소 동일이며 기록 실패의 backend 호출 0건을 별도 확인한다. 정상 대조에서 영속 저장 뒤 201. |
| 하드코딩 또는 직전 결과 재사용 | 초기화 없이 요청별 42·17을 공급한다. 독립 백엔드 결과와 각 ID의 레코드를 대조하고 변형 저장 증거를 동일 검사기가 거부한다. |

이전 정상 두 회차, 모든 403·422 직후 원본 ID 및 전체 필드 대조, 경계 호출과 독립 ingress의 일대일 대조를 보존했다. 공유 벡터의 직렬화와 SHA-256은 동결 전에 Python으로 대조했다. 제품 설계의 장애 시험과 코디네이터 배정 시험은 별개다.
