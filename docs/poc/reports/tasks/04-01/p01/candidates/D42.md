# Daily report archive

REQ-11. The daily report archive contains synthetic counts only.

REQ-12. The report publisher MAY publish an archive marked verified. It MUST NOT publish an archive marked unverified.

REQ-13. The report publisher role is the only principal allowed to publish. The reader role can only read.

AC-14. With the publisher credential, submit one verified and one unverified archive. Expect HTTP 201 and 422 respectively and exactly one stored archive. With the reader credential, submit the verified archive and expect HTTP 403 and no change in storage.
