# Daily report archive

REQ-11. Publication reads counts only from the synthetic-fixture source; production-derived sources are ineligible.

REQ-12. The report publisher MAY publish an archive marked verified. It MUST NOT publish an archive marked unverified.

REQ-13. The report publisher role is the only principal allowed to publish. The reader role can only read.

AC-14. Run the test twice. Before each run, empty the archive store and reset both source read counters. The synthetic-fixture and production-probe sources both return 42. Submit a verified archive with the publisher credential and expect HTTP 201. Immediately read the entire store. It must contain exactly one archive marked verified with count 42 and source identifier synthetic-fixture. Capture the record ID and all persisted fields. Submit an unverified archive with the publisher credential and expect HTTP 422. Immediately read the entire store and assert it contains only the captured record, with the same ID and identical persisted fields. Submit a verified archive with the reader credential and expect HTTP 403. Immediately read the entire store and repeat the same single-record identity and equality assertions. At the end of each run, assert one synthetic-fixture read and zero production-probe reads.
