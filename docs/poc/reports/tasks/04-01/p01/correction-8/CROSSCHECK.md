# F03 사전 대조

- REQ-11: 독립 ingress, publisher 자격의 직접 접근 거부, 등록·미등록 비허용 출처와 정상·변이 trace 비교를 유지했다.
- REQ-12: 기존 공통 바이트 벡터, 해시 불일치·증거 없음 대조에 실제 Verifier 발급/거부 관측과 공백 입력의 422 대조를 추가했다.
- 현재 요청의 출처 결과: 기록 실패·카운트 누락·42/17 대조를 유지한다. 형식·범위·출처·요청 불일치 및 직전 결과를 직접 주입해 503과 즉시 저장소 불변을 확인한다.
- 저장: 커밋 장벽에서 201 부재를 관측하고, 해제 후 커밋과 응답의 순서를 기록한다. 기존 정상 두 회차의 첫 레코드에서 6개 필수 필드와 값을 확인한 뒤 각 거부 직후 그 레코드와 대조한다.
- REQ-13: reader 및 무역할 인증 주체 각각에 유효·미검증 입력을 적용해 403 우선, 읽기 0, 저장소 불변을 확인한다.
