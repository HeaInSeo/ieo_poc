# Daily report archive

REQ-11. Publication reads counts only from the synthetic-fixture source; production-derived sources are ineligible.

REQ-12. The report publisher MAY publish an archive marked verified. It MUST NOT publish an archive marked unverified.

REQ-13. The report publisher role is the only principal allowed to publish. The reader role can only read.

AC-14. With the publisher credential, submit one verified and one unverified archive. Expect HTTP 201 and 422 respectively and exactly one stored archive. With the reader credential, submit the verified archive and expect HTTP 403 and no change in storage. Submit the same verified archive as a non-publisher administrator and expect HTTP 403 and no change in storage. Set up synthetic-fixture and production-probe sources with the same count of 42 and independent read counters initialized to zero. After all submissions, expect exactly one read of synthetic-fixture, zero reads of production-probe, and the stored archive to contain exactly the fixture count 42 with source identifier synthetic-fixture.
