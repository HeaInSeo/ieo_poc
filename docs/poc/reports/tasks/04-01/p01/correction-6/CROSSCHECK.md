# F03 사전 대조

| 반례 | 검출 관측 |
| --- | --- |
| 허용 경계를 호출한 뒤 같은 백엔드 직접 접근 | 발행자 실행 자격에서 두 백엔드 직접 호출 차단, 정상 경계 호출 대조, 독립 ingress와 허용 기록의 (요청, 출처) 다중집합 일치, 짝 없는 백엔드 이벤트를 넣은 검사기의 실패. |
| 등록된 출처를 전부 허용 | production-probe 정규 ID 거부 이벤트·backend 0건. 미등록 ID 거부와 정상 trace 검사기의 추가 사건 검출도 유지. |
| 검증 표시를 신뢰하거나 다른 검증 증거 재사용 | Verifier 정본의 정확한 ID·버전·내용 해시 증거만 201. 플래그 단독, 비신뢰 발행자, 각 바인딩 불일치는 각각 422·읽기 0·즉시 저장소 불변. |
| 비발행자에 대한 검증 오류가 권한 오류보다 먼저 반환 | reader 및 빈 역할 각각에 정상 인증을 확인한다. 유효 증거·미검증 각각에 403·읽기 0·직전 및 201 원본과 즉시 저장소 일치. |

정상 회차 두 번, 201 뒤 원본 ID·전체 저장 필드 고정, 각 거부 응답 직후 전체 저장소 대조, 동일 값의 두 출처 대조 및 블라인드 절차를 유지한다.
