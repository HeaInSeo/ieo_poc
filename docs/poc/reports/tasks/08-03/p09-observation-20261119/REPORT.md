# 08-03 P09 격리 관측

[첫 격리 실행 44514382183](https://github.com/HeaInSeo/ieo_poc/actions/runs/44514382183)은 원본 이벤트를 저장했고 판정에 실패했다. 정책 범위 내 관측에는 Tetragon의 `containerd://` 접두사가 포함됐다. Tetragon은 호출 경로 `/usr/local/bin/python3`을 기록했고 역할 영수증은 실제 실행 파일 `/usr/local/bin/python3.13`을 기록했다. 판정기가 두 표기를 그대로 비교해 동일 프로세스의 관측을 놓쳤다.

실패 아카이브에 교정된 판정기를 적용한 결과는 18개 행 중 17개가 기대 판정과 일치했다. 복구 직후 정책 카운터에는 훅 발생 1건이 기록됐고 수집본에는 해당 프로세스 시작만 있었다. 재시험은 역할 동작을 한 번만 수행하고 대응 이벤트의 로그 도착을 제한 시간 내에 확인한다.
