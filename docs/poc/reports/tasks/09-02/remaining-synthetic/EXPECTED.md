# 09-02 잔여 합성 범위 독립 기대값

기준은 동결 1e8de90과 현행 P33의 조합 실패·재개·비용·버전 행, v1.2 P33·§5.7·§9.12 및 현행 원장의 기준선 변경 기록이다. 후보는 773c975fd2dfc6c5741c11cc27dea33b443e0519. 아래 판정은 신규 입력 구성과 실행 전에 고정한다.

| ID | 자극 | 기대값 |
| --- | --- | --- |
| R1 | 같은 목표의 단독 PASS/채택과 별도 조합 FAIL/기각 | 단독 근거·편입 대기 유지, 조합 편입 차단, 무관 목표 유지. 새 결과 등록이나 실행은 자동으로 일어나지 않는다. |
| R2 | 보류 중인 회차에 재개 조건을 충족하는 새 검토·증거와 후속 회차 리비전 제출 | 이전 보류와 비용 기록 보존, 새 초안으로 해당 범위만 재개/편입 가능 상태. 증거 충족 전 대기, 같은 입력은 중복 초안을 만들지 않음. |
| R3 | 측정된 회차 사용량과 독립 출처가 있는 남은 작업 공수 추정을 동시 입력 | 원래 실측 값 유지, 추정 단위와 근거를 구조화 결과와 사람이 읽는 초안에 구분해 표시, 추정을 실측 합계에 가산하지 않음. |
| R4 | 동일 계측 파일의 같은 바이트를 다른 경로에 복사한 뒤 다른 회차에 귀속, 별도 대조에서 회차 식별자를 재지정 | 동일 측정 효과는 한 번만 계상. 기존 증거를 다른 회차에 재귀속한 채 유효 초안 발행 금지. 독립 측정으로 입증되지 않은 사용량을 별도 실측 비용으로 합산하지 않음. |
