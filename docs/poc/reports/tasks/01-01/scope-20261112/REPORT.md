# 01-01 · 목표·필수 기능·선택적 방법 범위표

실행 범위: 제공 문서에 근거한 로컬 설계 작업. 구현·런타임 실행·현재 서버 감사는 포함하지 않는다.
[범위·요구 산출물](Scope_and_Requirements.md)에 책임/제외와 73개 요구 ID별 산출물·수용 항목을 연결했다.
P15 비교 실행 제외, 후속 연구 분리, NodeKit/Sori 표본과 코디네이터 소유 repo 구분을 명시했다.
실제 repo URL·런타임·권한/예산·백로그·기한은 후속 바인딩 미확정이다. 그 사실을 실제 기능 없음/지원으로 단정하지 않는다.
검수: 별도 범위 대조 결과는 패키지의 validation/review_v1.3.3.md에 연결한다. 별도 검토는 범위·제외·요구 ID/수용 기준 연결을 확인했고 발견한 두 계약 문제도 보정 후 확인했다. 현재 01-01 설계 산출물은 검수 완료다. 이 판정은 런타임/제품 기능 검수와 별개다.
다음: 01-02 공식 문서 후보 비교와 사용자 선택. 선택 전 실제 probe·인증·운영 변경을 하지 않는다.
