# 02-08 후속 배정 및 주기 대조

승인된 코디네이터 배정 주체가 선행 작업과 정확한 현재 배정을 포함한 후속을 등록한다. PostgreSQL에 후속 작업·명세 revision·목표 SHA·승인 주체와 정책을 보존한다. 승인된 verdict의 커밋 직후, 코디네이터가 해당 사건을 사용해 맞는 후속을 즉시 대조한다. 사건을 놓치거나 전달에 실패하면 별도 프로세스가 같은 계획을 조회한다.

`ieo-followup-watch COORDINATOR_URL TOKEN_FILE REPO_ID SECONDS [--once]`는 코디네이터 DB 자격 없이 repo 범위의 서비스 자격 `followups:reconcile`로 주기 대조한다. 실패를 관측해 표준 오류에 남기고 복구 시 재관측한다. 이 자격으로 새 계획이나 직접 배정을 만들 수 없다.

두 경로는 계획 행을 잠그고 기존 배정의 spec·정책·선행 판정·기대 배정·시도 상한 검사를 재사용한다. 배정, 시도, 감사 이력과 후속 상태를 같은 트랜잭션에 커밋한다. 조건이 미충족되면 대기 사유를 남긴다. 성공한 경로와 선행 verdict 시각, 대조 관측 및 배정 시각을 분리한다. 이미 배정된 계획은 재실행하지 않는다.

## 격리 근거

- 승인 verdict 사건만으로 주기 실행 전 후속 1건을 배정한다. 미충족 상태에서는 0건이고 정상 대기다. watcher 자격은 plan 생성과 다른 repo 대조를 거부한다.
- 계획 등록 전 사건을 놓친 경우 실제 watcher 프로세스로 복구한다. 처분 쓰기 장애 주입 시 배정도 롤백된다. 재시작 뒤 재대조에서 후속 배정은 1건이다.
- 두 경로가 동시에 동일 행의 잠금을 기다리게 한 뒤 해제한다. 새 배정은 1건이며 후속 프로세스 재시작에서 기존 처분이 보존된다.

이 경로는 기존 배정까지 자동화한다. 모형 실행 전달에는 기존 승인·실행 조건·공유 사용량 검사가 적용된다. 실제 역할 인수·첫 행동 지연과 외부 감시 경보의 독립 수신 시험은 기존 04-11·07-05/P28 실측에서 확인한다.

## 독립 검토 보강

지정한 선행뿐 아니라 등록 명세의 다른 선행 verdict도 대조를 깨운다. 지정 선행이 먼저 완료되고 마지막 선행이 나중에 완료되는 모의 PostgreSQL 경로에서 watcher 실행 전 배정 1건을 확인한다. 시도 상한의 결정 사건·outbox와 대기 처분을 같은 트랜잭션에 보존하며 재시작 뒤에도 결정 요청은 한 건이다.

별도 watcher는 응답 장애와 함께 성공 응답의 `stalled` 관측을 읽는다. 수락이 확인된 현재 전달에 한해 첫 행동 기한(기본 60초)을 적용한다. 배정만 있고 전달되지 않았거나 예산이 거부된 정상 대기에서는 경보가 없다. 실제 P28 감지·수신 SLO 검증은 이월을 유지한다.

선행 조건이 `result_recorded`인 경우 해당 작업의 `not_accepted` verdict도 기록 사건으로 대조를 깨운다. 지정 선행에는 기존 그대로 정확한 배정에 대한 수용을 요구한다. 두 종류의 마지막 선행 사건을 각각 시험했고, 사건 수신은 계획 잠금 전에, 적격 판단은 기존 배정 검사 직후에, 배정 시각은 처분 기록 시에 기록됨을 확인했다. 적격 시각은 로컬 검사에서 조건 충족을 관측한 시각이다.
