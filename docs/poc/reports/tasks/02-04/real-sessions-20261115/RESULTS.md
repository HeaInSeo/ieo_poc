## 3. D3 중단과 재개

1. D3는 정상 종료했지만 사용량이 미계측으로 판정돼 호출자가 종료 코드 3으로 멈췄다. 재시도·우회는 없었다.
2. **원인**: 수집기가 `tool_use_result.usage`(자식의 마지막 응답만)를 자식 전체로 썼다. 누락된 첫 응답이 차액과 정확히 같았다([진행 기록 5](../child-usage-20261115/PROGRESS.md) §2).
3. **사용자 결정** [2026-11-15 D3](../../../../User_Decisions_2026-11-15_d3.md): 세션 증가분을 차감하되 자식 집계를 먼저 교정한다.
4. **교정**(PR #51, 검토 3회·교정 2회, 병합 d41e70f): 자식 전체는 자식 전사의 응답별 확정 사용량을 `message.id`마다 한 번 더한 값이다. 런타임 계약 revision 8 §12.
5. **정정**: 병합된 바이너리로 보존 기록을 재평가해 정정 줄을 덧붙였다.
   - 부모 6/160/456/33,595와 자식 4/64/2,157/2,067을 더하면 세션 증가분 10/224/2,613/35,662와 같다(`consistent`).
   - 차감값은 billable 2,847, cache_read 35,662다. 내부 예산 차감이며 추가 결제 승인이 아니다.
   - 원래 줄은 남아 있다. 정정은 기록을 읽을 때마다 다시 집계해 검증된다. D3를 다시 실행하지 않았다.
6. **재개 조건**(진행 기록 5 §11)을 모두 확인한 뒤 D4~D6을 이었다.
   - 예산 대조: 4회, 26초(셈), 14,474, 85,868. 진행 기록 5 §5와 같다.
   - 재시작 가드를 통과한 뒤 두 역할 컨테이너를 병합된 바이너리(`db2162c2…`)로 재시작했다. 체크포인트가 유지됐다.
