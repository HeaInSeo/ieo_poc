- 교체 전 두 역할이 유휴·중앙 모드였고 공유 quota 불일치는 0건이었다. 개발 마지막 회차는 R1, Guardrail은 마지막 회차 없음이었다. 코디네이터 health 200, 58090 활성 연결 0, 장부 진행 표식 없음, 루트 여유 8 GiB 이상을 확인했다. 실행 호스트의 Claude Code 세션 작업 경로를 대조해 이 저장소 권한 파일을 쓰는 세션이 없었으므로 U1을 생략했다.
- 두 역할을 교체해 동일 해시 및 유휴를 확인한 후 코디네이터를 교체했다. 코디네이터 사전 점검에서 호출 셸의 상속 함수가 검출돼 정지 전에 멈췄고, 해당 함수만 제거한 셸로 교체해 health 200을 확인했다.
- R1 전사 및 stream 해시를 대조했다. 정산 예행은 원본 장부를 유지했고, 승인 정산을 한 줄 추가한 뒤 코디네이터 예산 계획과 원본 행 보존을 재확인했다. R1b는 유효기간 내에 사용자가 전송했다.
- R2와 G1 직전에는 개발 역할의 최신 응답이 각각 `s8-r1b`, `s8-r2`의 종료와 `running: null`을 표시했다. 두 응답과 각 회차 후 코디네이터의 quota 응답은 운영 증거 목록에 있다.

이 문서는 실행 세션에서 확인한 항목의 요약이다. 운영 원본에는 장부·회차 응답·전송 직전 및 종료 상태가 있고, 계정 화면 원본과 모든 사전 점검 명령의 별도 로그는 공개 증거 목록에 포함하지 않았다.
