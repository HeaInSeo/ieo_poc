# 03-07 P08-COMMON 기대값

03-06에서 검증한 통합 Go·Rust 공통 이미지와 Guardrail UID 20002를 사용한다. 후보 파일은 `/work`에 읽기 전용으로 제공한다. 고정 이미지 안의 승인 검증기와 프로파일은 후보의 검사 목록을 읽지 않는다.

| 입력 | 경로 | 기대값 |
| --- | --- | --- |
| 정상 후보 | 승인 프로파일 | Go `TestDouble`과 Rust `tests::doubles_three`가 각 1회 통과, 생략 0건 |
| 결함 후보 + 필수 검사가 빠진 후보 목록 | 후보 자체 목록 | Go·Rust의 별도 smoke 각 1회 통과, 필수 계약 검사 실행 0건 |
| 같은 결함 후보 | 승인 프로파일 | smoke 각 1회 통과, 필수 계약 검사 각 1회 실패, 생략 0건 |
| 고정 이미지에서 컨테이너 새로 생성 | 승인 프로파일 | 고유 컨테이너 ID, 도구 버전·프로파일·파일별 SHA-256·검사 명령·판정 일치 |

결함 후보의 배수 함수는 입력을 그대로 반환한다. 후보 자체 목록은 0 입력만 확인하므로 결함을 놓치고, 필수 계약은 3 입력이 6으로 변환되는지 확인하므로 실패한다. 두 경로에 동일한 결함 후보 파일을 제공한다. 검증기와 프로파일의 출처는 03-06의 승인 이미지 digest로 고정한다.
