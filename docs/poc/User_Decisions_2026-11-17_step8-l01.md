# 사용자 결정 2026-11-17 · 02-05 단계 8의 L01 값과 실행안 요청

02-05 단계 8 절차서([RUNBOOK](reports/tasks/02-05/step8-runbook-20261117/RUNBOOK.md)) §10의 사용자 결정 목록에 대한 사용자의 답을 옮긴다.

## 1. 사용자 지시(원문 요지)

> 02-05 단계 8의 L01 값은 개발 1,800초·150,000토큰, Guardrail 600초·50,000토큰으로 승인한다. 기존 회당 제한과 전체 예산, 추가 청구 USD 0은 유지한다.
>
> 나머지는 네가 구체적인 실행안으로 작성해줘. 기존 시험 저장소 HeaInSeo/ieo_poc_test를 우선 검토하고, 정확한 repo·task_id·target_sha·branch_ref, R1·R2·G1 지시문, 등록자와 독립 의미 검토 주체, 백업 위치, 재배포 시간과 실패 시 대응을 채워 제시해줘.
>
> 정상적인 재배포와 R1→R2→G1을 한 번에 승인할 수 있도록 승인 요청을 묶어줘. 실행안 승인 전에는 실제 환경 변경과 모델 호출을 하지 말고, 필요한 준비는 계속 진행해줘.
>
> 예비 회차는 기존 결정대로 실패 원인과 증거를 보고한 뒤 건별 승인을 받는다. 승인된 정상 절차에서는 매 단계마다 다시 진행 여부를 묻지 않도록 해줘.

## 2. 반영

- **L01 값(단계 8 sprint revision의 한도).** 개발 `elapsed_seconds` 1,800·`total_tokens` 150,000, Guardrail `elapsed_seconds` 600·`total_tokens` 50,000. 셈법은 [사용자 결정 2026-11-16](User_Decisions_2026-11-16_l01-step5.md)(과금 토큰 3항, 회차 시간 합). 이 값은 단계 8 sprint revision에 대한 승인이며 다른 sprint의 L01 값은 정하지 않는다.
- **유지.** 02-05 예산 (나)의 회당 600초, 전체 2,400초·200,000·cache_read 2,000,000, 역할 몫, 추가 청구 USD 0, 02-04 예비 5회 미사용([사용자 결정 2026-11-15](User_Decisions_2026-11-15_0205-x08.md) §2.1).
- **실행안.** 개발 에이전트가 구체 실행안(대상 repo·task·SHA·branch, 지시문, 등록·의미 검토 주체, 백업 위치, 재배포 시간과 실패 대응)을 작성하고, 정상 재배포와 R1→R2→G1을 **한 번의 승인 요청**으로 묶는다. 승인된 정상 절차 안에서는 단계마다 다시 묻지 않는다. 절차서의 멈춤·중단 조건에 걸리면 멈추고 보고한다.
- **예비.** 기존 결정대로 실패 원인과 증거를 보고한 뒤 건별 승인([사용자 결정 2026-11-17 예비](User_Decisions_2026-11-17_spare.md) §4).
- **승인 전 금지.** 실행안 승인 전에는 실제 환경 변경(58090 코디네이터, 55433 영속 DB, 역할 컨테이너·볼륨, 자격 파일)과 모델 호출을 하지 않는다. 읽기 전용 준비와 문서 작업은 계속한다.
