## 2. 조건(사용자 지시 그대로)

### 2.1 복구 승인과 실행
- 복구 승인은 사람으로 확인된 운영 주체만 발급한다. `roles:control` 보유 여부뿐 아니라 호출 주체도 확인하고, 개발·Guardrail 자격의 자체 승인은 거부한다.
- 승인자·사유·시각과 대상 배정·세대·미완료 체크포인트를 중앙에 기록한다.
- 다음 전달은 승인된 대상에 한해 새 세션을 시작한다. 기존 세션 재개와 구분한다.

### 2.2 복구 조건
- 단계 7의 GitHub head 대조를 재사용한다. 현재 대조가 신뢰 입력 기반인지 실제 수집 기반인지도 명시한다.
- 기존 실행이 진행 중이면 거부한다. 실행 종료나 외부 요청 결과를 확인할 수 없다면 확인 필요 상태와 근거를 남기고 복구 실행을 보류한다.
- 승인 이후 대상 체크포인트·세대·head가 달라지면 다시 대조한다.
- 복구 승인 하나는 한 실행에만 사용하며, 중복 요청이나 응답 유실로 실행이 두 번 생기지 않게 한다.

### 2.3 기록과 예산
- 이전 체크포인트·실험 증거는 보존하고 복구 이력을 추가한다.
