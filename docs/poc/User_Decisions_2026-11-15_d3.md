# 사용자 결정 2026-11-15 · 02-04 D3 사용량 처리와 자식 사용량 집계 교정

사용자 지시의 요지를 원문 표현대로 옮긴다. 반영은 [02-04 진행 기록 5](reports/tasks/02-04/child-usage-20261115/PROGRESS.md)와 런타임 계약 revision 8(§12)에 있다.

> D3는 1번, 세션 누적 증가분을 예산에서 차감하는 방향에 동의합니다. 다만 원인이 확인됐으므로, 불일치를 허용하는 규칙 변경만으로 끝내지 말고 자식 사용량 집계를 교정한 뒤 재개하세요.

**확인된 원인**(기존 기록 대조, 새 모델 호출 없음):
- D3는 D2와 같은 세션을 재개했고 재개 기준도 D2와 일치한다.
- 자식 에이전트는 모델을 두 번 호출했다.
- 수집기가 자식 전체 사용량으로 채택한 `tool_use_result.usage`는 자식의 마지막 모델 응답 사용량과 일치했다.
- 누락된 첫 응답(입력 2, 출력 61, cache_creation 2,067, cache_read 0)이 보고된 차액과 정확히 일치한다.
- 따라서 D3의 예산 집계 대상은 billable 2,847, cache_read 35,662다. **이는 내부 예산 차감이며 추가 결제 승인이 아니다.**

**지시**:
1. 다음 기동의 설정 정리로 자식 상세 기록이 지워지기 전에 관련 원본과 해시를 저장소 밖 비공개 위치에 보존한다. D3의 최초 미측정 판정과 중단 이유도 보존한다. 원본 stream·자격·세션 본문은 공개 저장소에 올리지 않는다. 공개 회귀 자료는 필요한 수치·구조만 남긴 비식별 자료로 만든다.
2. `tool_use_result.usage`를 항상 자식 전체 누적이라고 가정하지 않는다. 확정된 응답별 기록으로 자식의 전체 모델 응답을 중복 없이 합산한다.
   - 실시간 stream의 사용량은 하한일 수 있으므로, 중간 관측값을 최종 사용량으로 확정하지 않는다.
   - 부모 사용량, 자식별 전체 사용량과 근거, 세션 누적 증가분, 귀속 대조 결과, 실제 예산 차감값을 구분해 기록한다.
   - 세션 증가분이 부모＋자식 합보다 크다는 조건만으로 모든 불일치를 허용하지 않는다. 확정 자료가 부족하거나 설명되지 않는 차이가 남으면 미측정·중단 규칙을 유지한다.
3. 재현과 교정 검증에는 새 실제 Claude 호출을 쓰지 않는다. 필수 확인 항목:
   - D3 자식 두 응답 합산이 네 토큰 항목 모두에서 세션 증가분과 일치한다.
   - 같은 응답의 중복 기록·갱신을 중복 합산하지 않는다.
   - 마지막 응답만으로 전체를 확정하지 않는다.
   - 잘못된 재개 기준·세션 불일치·누적 감소를 계속 차단한다.
   - guard가 중단한 실행은 종료 직전 결과가 있어도 미측정이다.
   - 최종 결과나 필요한 계측 근거가 없으면 다음 호출을 차단한다.
   - 기존 부모·자식·재개·압축 회귀 시험을 유지한다.
4. 검증 후 D3의 재평가·정정 근거를 기록한다. 최초 기록과 정정 전후를 추적할 수 있게 하고, 같은 실행을 새 회차로 세거나 두 번 차감하지 않는다. D3를 다시 실행하지 않는다.
5. 검토·병합·main CI 확인과 예산 기록 대조가 끝나면 기존 예산 안에서 D4~D6을 이어간다. 예산 초기화, 자동 재시도, 추가 결제는 허용하지 않는다.
