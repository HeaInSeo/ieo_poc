- **목표**: “사람 재지시 없이 자동 진행”에 더해 “정상 경로에서 다음 정기 회차를 기다리지 않고 후속 작업을 인수한다”를 검증한다.
- **기준선 불변.** 주계획 73·후속 12 작업, 실험 31·5의 분모, 완료 이력과 완료 수를 바꾸지 않는다. 새 실험이나 작업을 만들지 않고 기존 P28과 그 작업에 보강한다. 바뀌는 세 작업은 모두 미착수다.
- **수용 기준 변경(프로파일 rev 7)**:
  - **02-08**(구현): 사건 기반 정상 경로와 보조 경로인 정기 대조를 분리하고, 조건 충족·사건 수신·배정·실제 인수·첫 행동의 시각과 실행 원인을 기록한다. 남은 CI·검토·승인·예산 조건은 정상 대기로 두고 생략하지 않는다.
  - **04-11**(검증): 정기 대조를 끄거나 긴 간격으로 두고 그 전에 실제 인수·첫 행동까지 진행됨을 확인한다. 허용 지연과 측정 방법은 실행 전에 고정한다. 사건 누락은 정기 대조로 복구되고 중복·지연·재시작에도 중복 배정·상태 변경이 없다. 남은 CI·검토·승인·예산 조건은 정상 대기로 구분한다.
  - **07-05**(검증): 실제 흐름에서 사건 경로와 정기 대조 복구를 실행 원인과 시각으로 구분해 보고한다.
- **스프린트 revision**: POC-02 → 7, POC-04 → 6, POC-07 → 6. 해당 작업의 기준만 바뀌고 다른 작업은 그대로다.
- **검증 계획**: P28-F 사례 3개를 추가한다(사건 기반 즉시 인수, 사건 누락과 정기 대조 복구, 정상 대기와 조건 유지). 기존 P28-F·P28-M 행은 바꾸지 않는다.
- **04-12**(P28-M 별도 감시)의 기준은 바꾸지 않는다. 정기 대조의 복구 역할은 04-11의 누락 사례로 판정한다.
