**v1.0 당시 구조 점검 기록.** 5.2절의 기본 노드 46개와 문장으로 명시한 조건부 선행·P30 후보 준비 검증을 포함한 48개 노드·222개 선행 연결을 위상 정렬했다. 순환 0건, 미정의 선행 ID 0건이다. 개선 문서의 재검증은 새 버전 노드로 분리한다. Markdown 표의 열 수, P01~P32 ID 보존·중복, 기존 결과표와 참조 링크 형식을 함께 점검했다.
