## 4. 정식 설계·개발에 넘길 재발 방지 기준

실제 발견한 원인마다 다음 대응표를 작성한다: “발견한 문제 → 원인 → 정식 설계 요구사항 → 자동 검증·회귀 자료 → 담당 작업·완료 조건 → 남은 한계”.

최소한 다음 원인을 포함한다:
- 사용량 의미 오해
- 누락과 0의 혼동
- 재개 기준 오류
- 정정과 이력 훼손
- 파일 위치 의존
- 시험 기준의 모호함
- 실행 코드와 증거 불일치
- 완료 범위의 혼동
- 런타임 갱신

> 이미 교정한 결함은 재현 자료와 자동 검사에 연결하세요. 정식 설계 문서에는 이 대응표를 근거로 반영하고, 추가 검증이 필요한 가정은 명시하세요.
