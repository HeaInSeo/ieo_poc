다음 두 결함은 02-03 전에 교정해줘.

- 합법적인 옛 배정의 늦은 결과는 원 SHA·배정에 보존하되 현재 판정에 사용하지 않는다. 기존 요청의 멱등 재조회와 새 stale 실행 요청을 구분한다.
