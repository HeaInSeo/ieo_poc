# 사용자 결정 2026-11-14 · P28 사건 기반 즉시 인수 기준 보강

사용자 지시의 요지를 원문 표현대로 옮긴다. 반영은 [개정 v1.3.3-A5](Amendment_v1.3.3-A5.md)에 있다.

> 현재 02-04는 기존 순서대로 계속 진행하세요. 다음 계획 갱신에서 기존 P28과 관련 구현·시험 작업에 아래 기준을 보강하세요.

> 목표는 “사람 재지시 없이 자동 진행”에 더해, “정상 경로에서 다음 정기 회차를 기다리지 않고 후속 작업을 인수한다”는 것을 검증하는 것입니다.

1. 정상 경로는 완료·검토 결과 등의 사건을 받아 필요한 조건을 대조하고 후속 처리를 시작하도록 정의한다. 정기 대조는 이벤트 누락·중단 후 복구를 담당하는 보조 경로로 구분한다.
2. 정상 시험에서는 정기 대조를 일시적으로 비활성화하거나 충분히 긴 간격으로 설정한다. 정기 대조가 실행되기 전에 후속 담당자의 실제 인수·첫 행동까지 진행됐음을 실행 원인과 시각 기록으로 확인한다.
3. 필수 조건이 모두 충족된 시각, 사건 수신, 배정, 실제 인수, 첫 행동을 구분해 기록한다. 조건 충족부터 인수·첫 행동까지의 허용 지연과 측정 방법은 실행 전에 근거와 함께 고정한다.
4. 완료 이벤트 누락 시험에서는 정기 대조를 통해 복구되는지 확인한다. 이벤트 중복·지연 도착·재시작이 겹쳐도 중복 배정이나 중복 상태 변경이 없어야 한다.
5. CI·독립 검토·승인·예산 등 필요한 조건이 남아 있는 경우는 정상 대기로 구분한다. 빠른 인계를 이유로 기존 조건을 생략하지 않는다.
6. 기존 02-08·04-11·07-05 등과 대조해 반영 위치를 정하고, 별도 실험을 중복 생성하지 않는다. 이 요구사항은 전송 방식과 독립된 실행 계약으로 두며 gRPC 도입을 새로운 선행 조건으로 추가하지 않는다.
