- **기준선 불변.** 주계획 73·후속 12 작업, 실험 31·5의 분모와 수용 기준·프로파일·명세 revision을 바꾸지 않는다. 검수 완료 작업의 수용 기준을 소급 변경하거나 완료 판정을 취소하지 않는다. 추가 작업은 `state.json`의 `extra_tasks`에 두고 완료 수·진행률에 넣지 않는다.
- **X-03** gRPC 내부 API 계약과 분리 영향 확인(설계, 선행 02-03).
- **X-04** gRPC 경로 구현과 HTTP·gRPC 공통 회귀(구현, 선행 X-03).
- **X-05** 기본 kind(Cilium 없음, 멀티 노드) gRPC 서비스 발견·분산·장애 복구 시험(검증, 선행 X-03).
- **X-06** 제품 경로 kind 재검증(검증, 선행 X-04·X-05).
- **X-07** Cilium L7 분산 경로 추가 시험(검증, 선택, 선행 X-05). 미실행이 다른 작업을 막지 않는다.
- 수용 기준 원문은 장부 §7과 기계 판독본에 있다.
- 제외: Claude CLI 실행 방식과 GitHub·Notion 외부 API 연결의 변경, 모델 예산 확대·자동 재시도 추가, 기존 개발 클러스터·운영 DB 변경. kind 결과를 물리 서버 장애·실제 서버 간 단절·운영 처리량 검증으로 표현하지 않는다.
- 현재 승인된 작업(02-04 등)은 기존 범위·수용 기준대로 진행하며 X-03~X-07은 그 선행이 아니다. X-02의 새 선행도 아니다.
- 문서 정합: 장부 §7, 패키지 검산기(A4 순차 적용).
