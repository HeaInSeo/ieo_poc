# 이번 개정에 적용한 사용자 결정

2026-11-11 KST · 최신 U3은 사용자가 전달한 독립 리뷰의 「새 사용자 결정」에 근거한다.

U1 (2026-11-10, **U3으로 대체됨**). repo마다 컨테이너 하나 안에 개발 에이전트와 Guardrail을 두는 이전 기록이다. 경위는 첨부 리뷰에 보존하며 현재 실행 지시로 사용하지 않는다.

U3 (2026-11-11, 현재). **repo마다 개발 Pod 하나와 Guardrail Pod 하나를 따로 두며 각 Pod는 컨테이너 하나다.** `<repo>-dev`, `<repo>-guardrail`과 공통 repo 라벨을 쓴다. 역할별 UID·파일시스템·자격·영속 볼륨을 두며 쓰기 가능한 공유 볼륨을 두지 않는다. 같은 호스트 단계에서는 컨테이너 둘이다. supervisor는 Pod별 PID 1로 자기 역할만 관리한다. 중앙 코디네이터 단일 활성 결정과 D1~D8 나머지는 유지한다.

U3은 배치 결정을 바꾼다. 역할별 상시 유지 또는 idle 정지까지 승인한 뜻은 아니며 해당 운영 정책은 P34 측정 뒤 결정 필요다. 원 2026-11-04 설계 로그는 역사적 원문으로 보존한다.
